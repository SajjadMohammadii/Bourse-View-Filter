# Bourse-View-Filter

داشبورد امتیازدهی و فیلتر نمادهای بورس تهران — **کاملاً محلی و بدون سرور**.
فایل اکسل روزانه `screener-plus-YYYY-MM-DD.xlsx` را در مرورگر بارگذاری کنید؛ همه پردازش‌ها روی همان دستگاه انجام می‌شود.

- پلن کامل پروژه: [PLAN.md](PLAN.md)
- ساخت نسخه تک‌فایلی: `npm install && npm run build` ← فایل `dist/index.html` را با دابل‌کلیک باز کنید.
