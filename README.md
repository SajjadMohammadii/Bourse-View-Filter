# Bourse-View-Filter

داشبورد امتیازدهی و فیلتر نمادهای بورس تهران — **کاملاً محلی و بدون سرور**.
فایل اکسل روزانه `screener-plus-YYYY-MM-DD.xlsx` را در مرورگر بارگذاری می‌کنید؛ همه پردازش‌ها روی همان دستگاه انجام می‌شود و هیچ داده‌ای به جایی ارسال نمی‌شود. نسخه نهایی فقط یک فایل `index.html` است که با دابل‌کلیک و بدون اینترنت باز می‌شود.

پلن کامل و منبع حقیقت پروژه: [PLAN.md](PLAN.md)

---

## نصب (یک بار)

پیش‌نیازها: [Node.js](https://nodejs.org/) نسخه ۲۰ یا بالاتر، [Git](https://git-scm.com/)، و (برای توسعه) [VS Code](https://code.visualstudio.com/).

در ترمینال VS Code (`` Ctrl+` ``):

```bash
git clone https://github.com/SajjadMohammadii/Bourse-View-Filter.git
cd Bourse-View-Filter
code .                      # باز کردن پروژه در VS Code

npm run setup               # نصب همه وابستگی‌ها + مرورگر تست (Playwright)

# افزونه‌های پیشنهادی VS Code (ESLint، Prettier، Vitest، Playwright):
code --install-extension dbaeumer.vscode-eslint
code --install-extension esbenp.prettier-vscode
code --install-extension vitest.explorer
code --install-extension ms-playwright.playwright
```

> اگر `code` در ترمینال شناخته نشد: در VS Code کلید `Ctrl+Shift+P` ← «Shell Command: Install 'code' command in PATH».
> با باز کردن پروژه، VS Code خودش هم نصب افزونه‌های پیشنهادی را پیشنهاد می‌دهد.

## دیدن نتیجه

| روش | دستور | سپس |
|---|---|---|
| حالت توسعه (به‌روزرسانی خودکار با هر تغییر کد) | `npm run dev` | آدرس <http://localhost:5173> را در مرورگر باز کنید |
| نسخه نهایی تک‌فایلی | `npm run build` | روی `dist/index.html` دابل‌کلیک کنید (بدون سرور و بدون اینترنت) |

فایل `dist/index.html` را می‌توانید به هر کسی بدهید؛ برای اجرا به هیچ نصبی نیاز ندارد.

## راهنمای استفاده

### ۱. بارگذاری فایل روز
دکمه **«بارگذاری فایل روز»** را بزنید یا فایل اکسل را روی صفحه بکشید و رها کنید. تاریخ اسنپ‌شات از نام فایل خوانده می‌شود (مثلاً `screener-plus-1405-08-04.xlsx` ← ۱۴۰۵/۰۸/۰۴). پردازش ۹۵۷ نماد حدود ۱٫۵ ثانیه طول می‌کشد.
آخرین فایل در مرورگر ذخیره می‌شود؛ با رفرش صفحه دوباره بارگذاری لازم نیست.

### ۲. صفحه‌ها
| صفحه | چه چیزی نشان می‌دهد |
|---|---|
| **نمای کلی** | شاخص‌های کلیدی، نقشه ربع‌ها (ستاره‌ها / ارزان‌های فراموش‌شده / حباب‌های مومنتوم / پرهیز)، ۱۰ نماد برتر، تازه‌واردهای ۲۰ برتر، نقشه بازار |
| **تکنیکال، بنیادی بلندمدت، فصلی، ماهانه** | بهترین‌ها و بدترین‌ها، جدول کامل، نقشه حرارتی فاکتورها، توزیع امتیاز، میانگین بخش‌ها؛ پریست وزن و ویرایش وزن‌ها با اسلایدر؛ تب «متحول‌شده‌ها» در فصلی و ماهانه |
| **ریسک بازار** | دماسنج ریسک (هم‌وزن / وزن ارزش بازار / ریشه ارزش بازار)، مؤلفه‌ها، ریسک بخش‌ها، جریان پول حقیقی، روند زمانی |
| **استودیو فیلتر** | سازنده بصری شرط‌ها ↔ عبارت متنی، پریست‌ها، پیش‌نمایش زنده و خروجی Excel/CSV |
| **پارامترهای سفارشی** | تعریف ستون جدید با فرمول (مثلاً `C_QtrShare = NI_MRQ / NI_FY`) و افزودن آن به فاکتورها |
| **داده خام / سلامت داده** | همه ستون‌ها با انتخاب‌گر ستون؛ گزارش ستون‌های جدید/حذف‌شده، پوشش داده و تغییرات نسبت به روز قبل |
| **تنظیمات** | تورم، نرخ بدون ریسک، آستانه‌ها، وزن امتیاز ترکیبی، واحد مبالغ، ارقام فارسی/لاتین، ویرایشگر پیشرفته پروفایل‌ها، تاریخچه و پشتیبان‌گیری |

روی هر نماد (در جدول‌ها یا نمودارها) کلیک کنید تا **کشوی جزئیات** باز شود: رادار چهار پروفایل در کنار میانه صنعت، ریز متریک‌ها با صدک بازار و صنعت، سطوح حمایت و مقاومت، تاریخچه امتیاز و مقایسه با حداکثر ۴ نماد. جستجوی نماد: `Ctrl+K`.

### ۳. زبان فیلتر (خلاصه)
عبارت را در کادر «فیلتر سراسری» (بالای صفحه) یا در استودیو فیلتر بنویسید و Enter بزنید.

```text
score.technical >= 60 AND Exchange IN ("TSE", "IFB")
NI_MRQ / NI_FY > 35% و نه flag.staleStatement
PtoE_ttm BETWEEN 0 AND 7 AND real(NI_3YrGR) > 10%
MarketCap > 50همت AND [OP-Margin-MRQ-3qGR] IS NOT NULL
top_n(score.composite, 20) OR industry_pct(ROE) > 90
```

- عملگرها: `> >= < <= = !=`، `AND / OR / NOT` (یا `و / یا / نه`)، `IN (…)`، `BETWEEN … AND …`، `CONTAINS`، `IS NULL`.
- اعداد: `20%` یعنی ۰٫۲، `5همت` یعنی ۵ هزار میلیارد تومان، پسوندهای `K M B T`؛ ارقام فارسی هم پذیرفته می‌شوند.
- فیلدها: هر ستون اکسل، پارامترهای مشتق `D_…`، سفارشی `C_…`، و `score.<پروفایل>`، `factor.<پروفایل>.<فاکتور>`، `conf.…`، `rank.…`، `grade.…`، `flag.…`، `delta.score.…`. نام‌های دارای `-` را داخل `[ ]` بنویسید.
- توابع: `abs min max log ln sqrt pow round floor ceil clamp sign coalesce ifnull isnull if safe_div real annualize cagr pct_rank sector_pct industry_pct zscore sector_avg sector_median industry_median rank top_n contains starts_with`.
- مقدار خالی مثل SQL رفتار می‌کند: مقایسه با مقدار خالی «نادرست» است؛ برای بررسی از `IS NULL` استفاده کنید.
- خطاها با محل دقیق و پیشنهاد نام درست نمایش داده می‌شوند («ستون NI_MRQQ پیدا نشد. منظورتان NI_MRQ است؟»).

### ۴. تاریخچه
با هر بارگذاری، خلاصه امتیازها در مرورگر ذخیره می‌شود. از روز دوم به بعد ستون **«تغییر نسبت به قبل»**، **تازه‌واردهای ۲۰ برتر**، روند دماسنج ریسک و نمودار تاریخچه امتیاز هر نماد فعال می‌شود. پس از ۲۰ اسنپ‌شات، ریسک بازار نسبت به تاریخچه خود بازار سنجیده می‌شود.

### ۵. پشتیبان‌گیری
همه داده‌ها فقط در همین مرورگر (IndexedDB) ذخیره می‌شوند. از صفحه تنظیمات می‌توانید تنظیمات، پارامترهای سفارشی، پریست‌ها و تاریخچه را به JSON خروجی بگیرید و در مرورگر دیگر وارد کنید.

## برای توسعه‌دهندگان

| دستور | کار |
|---|---|
| `npm test` | تست‌های واحد و golden (Vitest) |
| `npm run test:e2e` | ساخت نسخه نهایی و تست‌های مرورگر (Playwright، با Chrome سیستم) |
| `npm run lint` | ESLint (شامل مرزهای معماری) و بررسی نوع‌ها |
| `npm run audit:a11y` | ممیزی دسترس‌پذیری Lighthouse روی همه صفحه‌ها با داده (پس از `npm run build`) |
| `npm run format` | قالب‌بندی خودکار کد |

ساختار لایه‌ها: `ui → app → core ← config` (اجباری با ESLint). `core` هیچ دسترسی به DOM یا ذخیره‌سازی ندارد.

| می‌خواهم… | کجا |
|---|---|
| پارامتر مشتق جدید | `src/config/derivedMetrics.ts` + تست در `tests/unit/metrics/derived.test.ts` |
| فاکتور یا وزن پیش‌فرض | `src/config/profiles/<profile>.ts` |
| پروفایل جدید | فایل جدید در `src/config/profiles/` و ثبت در `index.ts` (صفحه‌اش خودکار ساخته می‌شود) |
| تابع زبان فیلتر | `src/core/filters/functions.ts` |
| پریست فیلتر | `src/config/filterPresets.ts` |
| قوانین ویژه یک صنعت | `src/config/industryOverrides.ts` |
| برچسب/دسته ستون جدید اکسل | `src/config/columns.ts` (ستون ناشناخته بدون این کار هم قابل استفاده است) |

### نکته‌ها
- فرض‌های فهرست‌شده در بخش ۱۷ پلن (مثلاً معنای `Rev_3MGR` یا `IndividualBuyPower`) هنوز باید با منبع داده تأیید شوند.
- «همت» طبق تعریف پلن = هزار میلیارد تومان = ۱۰^۱۳ ریال؛ بنابراین ارزش بازار «ذوب» ۳۷٫۰۹ همت نمایش داده می‌شود.
- رنگ متن کم‌رنگ (`--text-faint`) برای رسیدن به کنتراست ۴٫۵:۱ کمی روشن‌تر از مقدار پلن انتخاب شده است.
- فایل نمونه `data/samples/screener-plus-1405-08-04.xlsx` برای تست‌های golden در مخزن قرار دارد.
